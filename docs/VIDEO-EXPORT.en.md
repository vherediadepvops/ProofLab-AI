# Download the video with overlays

In Understand, **Download video** saves the complete clip with the visible layers: tracking, vectors, measurement labels and ghost trail. Enable the desired layers before downloading. Display zoom does not crop the output.

The browser creates the silent copy at normal playback speed, at the video's displayed source resolution. It chooses MP4 when supported for recording, otherwise WebM. No additional Meta call is made and saved measurements remain unchanged. This is a visual copy for sharing; retain the original as the measurement source.

Keep the tab visible until completion. Progress appears beside the controls and the operation can be cancelled. Playback position and speed are restored on completion or cancellation. Layer, seek, speed and suspension controls are locked during export; changes to the study, language or evidence cancel the copy. Interruptions, errors or a hidden tab never produce a partial download presented as complete.

Export uses the player's existing canvas and decoded video-frame timestamps. This is a real-time visual recording: output cadence depends on browser capacity and does not replace the original or SAM evidence. Missing measurements remain gaps.
